# 独立设置窗口（开发版）

设置采用原生 Qt 控件与系统主题，只有输入、快捷键、词库、翻译四页；不在每次输入时重复显示模式提示。窗口启动不会写配置、启动翻译、联网或重启输入法。

## 启动与范围

Linux 桌面需要 Python 3 与 PySide6。运行 `python3 settings/app.py`，或安装独立桌面入口后从应用菜单打开“TransIME 设置”。开发阶段安装和运行均在虚拟机中执行：`python3 tools/install_settings.py`。此安装器只安装设置窗口，不替换输入法引擎，不自动安装依赖，不导入任何词库；普通安装遇到已有目标会拒绝覆盖。

同一安装器支持 `--upgrade` 与 `--uninstall`：先核对安装清单、文件摘要及目录内容，仅管理它自己安装且未被修改的文件。用户修改过的文件、额外文件、符号链接和无清单的旧安装均拒绝处理，不强行覆盖或删除。升级失败会尝试回滚；卸载保留输入法配置和用户词库。清单用于文件归属和变更检查，不是软件签名或对恶意并发修改的安全保证。

隔离验证须显式指定 `--config-home /var/tmp/某个测试目录/config` 与 `--data-home /var/tmp/某个测试目录/data`，不使用真实用户数据。正常启动尊重 `FCITX_CONFIG_HOME`、`FCITX_DATA_HOME` 或对应 XDG 目录。

“保存设置”只写配置。“重新加载输入法”需在完成草稿后另行确认：通过会话总线的 `ReloadAddonConfig transime` 直接重载组件，先检查输入法是否运行，不自动启动它。普通 `fcitx5-remote -r` 只重载全局配置，不能用于使 TransIME 自定义按键生效。发送重新加载请求不代表已经验证当前输入上下文读取了所有新设置。

Linux 配置后端在最终内容检查、替换与快照更新期间持有目录级保存锁，避免两个设置窗口同时成功保存却互相覆盖。锁在进程退出时自动释放，不留下永久锁文件。不遵守此锁的外部编辑器仍可能竞争，不能把内容检查与协作锁称为对所有外部修改的绝对保护。

独立词包另用词库页的“加载词包”，在确认后请求拼音引擎的 `dictmanager` 子配置接口重新读取词包。普通 `fcitx5-remote -r` 只重载配置，不加载新增词典。缺少 gdbus 或当前桌面会话不可连接时，词包仍保留在磁盘，可结束输入后退出并重新打开输入法。不会以普通系统命令重启并误绕过私有版本启动器。显式选择与默认路径不同的测试配置/数据目录时，窗口禁止向当前桌面会话发出加载或重载请求。

## 兼容边界

新快捷键与静默模式需要配套更新的插件和拼音桥接组件。仅在旧版 0.1.4 上安装窗口不会升级这些能力。当前适配 Fcitx5 全拼，不宣称支持 Windows 原生输入接口、Rime 或双拼。跨平台设置窗口的可移植性不能当作跨平台输入法已经完成。

词包见 [词包格式](dictionary-format.md)。导入时先验证和预览，再编译回读；只管理独立词包，不读取 `user.dict`、历史或个人词库备份。源码示例是人工编写的公开示范词条。英文释义暂不接入翻译。

翻译页如实展示现有引擎的限制。大模型实验独立于日常插件，不因下载或跑通一次就加入正式可选模型；模型更换必须经过质量与资源验收。

## 开发测试

在虚拟机源码目录执行：

```sh
python3 -m unittest discover -s tests -p 'test_dictionaries.py' -v
python3 -m unittest discover -s tests -p 'test_settings_configuration.py' -v
xvfb-run -a python3 -m unittest discover -s tests -p 'test_settings_ui.py' -v
```

这些测试使用临时配置和人工词条。界面自动测试不替代真实桌面的按键与输入法集成测试。
