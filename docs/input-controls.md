# 输入模式与快捷键

设置窗口统一管理输入模式和快捷键。`ContinuousComposition=True` 使用整段组合；
`False` 使用原生拼音候选行为。切换模式或关闭插件时，已有整段草稿保留到明确
提交或取消，模式变更在该草稿结束后生效。`Enabled` 控制翻译插件是否启用。

整段模式默认不重复显示中英文状态说明，`ShowModeHints=False`。候选译文仍可独立
通过 `CandidateTranslations` 控制。需要语言提示的用户可在设置中开启
`ShowModeHints`；容量或翻译错误等必要反馈不受这一选项控制。

以下配置采用 Fcitx 的 KeyList 格式，每个操作对应一个节，节中 `0=...`、
`1=...` 表示可选快捷键。示例 `Control+Return`、`Alt+F8`、`Shift+space`。

| 配置键 | 默认值 | 作用 |
| --- | --- | --- |
| `TranslateKey` | `Control+Return` | 提交已就绪的译文 |
| `ChineseCommitKey` | `space` | 提交整段中文及原样保留的字面文本 |
| `RawCommitKey` | `Return`, `KP_Enter` | 提交整段原始拼音及字面文本 |
| `LiteralSpaceKey` | `Shift+space` | 在整段草稿内插入空格 |
| `ClearHistoryKey` | `Control+Alt+BackSpace` | 清除本地短期翻译历史 |
| `ToggleKey` | 空 | 可选的插件启用/关闭键 |

中文提交、原始输入提交和插入空格必须至少各绑定一个键。其他三项可留空。
同一个标准化后的组合不能绑定多个操作；快捷键不能是普通无修饰字符、纯修饰键
或键码。可用空格、回车、小键盘回车、功能键，或带 Control/Alt/Super 等修饰键
的组合。`Control+space` 保留给整段内部语言切换；无草稿时仍遵循 Fcitx 的全局
切换设置。Shift 轻按的中英文切换及 Escape 取消行为仍保留，不是本次新增的
可配置操作。设置窗口还应提醒用户检查 Fcitx 全局键和应用快捷键是否冲突。

插件通过 `transimeSetControlsV1` 将真实按键绑定交给拼音桥接层，而不是仅修改
显示文字。新桥接层保留原 V1/V2 接口。旧桥接层仍使用历史固定整段按键，不能
宣称支持新自定义整段操作；应随本次版本同时升级桥接层和插件。

配置接口拒绝有冲突的绑定并保留原配置。手动编辑文件后重新加载时，非法按键
组恢复到默认按键（不改写原文件），其他配置保留。系统级全局快捷键冲突不在
这个局部验证器的识别范围内。

重新绑定提交操作后，整段草稿中的未绑定裸空格作为字面空格插入；未绑定裸回车
及小键盘回车不会透传给应用，避免在草稿尚未提交时触发发送。无草稿时保持
应用自身的按键行为。

验证入口为隔离的 `tests/fcitx/headless_test.cpp --mixed`，其中新增自定义中文、
原始输入、字面空格、关闭/重新启用、草稿保留、提示开关及冲突拒绝检查。
应只在测试虚拟机运行；合成输入测试不能替代真实桌面应用验收。
